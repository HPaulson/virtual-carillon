# Virtual Carillon Home Assistant integration

Copy this directory into `/config/custom_components/virtual_carillon`, start the Node engine, and add **Virtual Carillon** from Settings → Devices & services. Enter the API URL and the server's `VIRTUAL_CARILLON_API_TOKEN` when prompted. The integration Configure flow provides general playback distance settings, a simple Westminster setup, plus unlimited manual or automatic schedules: Manual selects a specific asset or hymn, while Automatic lets LitCal choose a hymn, optionally filtered to a canonical hour. Schedules support multiple times, days, time windows, and Home Assistant media-player targets. The integration exposes a browsable media source and target-based actions, so Home Assistant chooses the actual media players. The Node container does not need access to speakers, PipeWire, ALSA, or Bluetooth. The status sensor exposes the hymn catalog and today's normalized LitCal day. Advanced `virtual_carillon.select_hymn` filters remain available for automations.
