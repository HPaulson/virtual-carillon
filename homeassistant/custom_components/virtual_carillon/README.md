# Virtual Carillon Home Assistant integration

Copy this directory into `/config/custom_components/virtual_carillon`, start the Node engine, and add **Virtual Carillon** from Settings → Devices & services. Enter the API URL and the server's `VIRTUAL_CARILLON_API_TOKEN` when prompted. The setup flow also configures LitCal usage and calendar selection; those values can be changed later in the integration Options flow. The integration exposes a browsable media source and target-based actions, so Home Assistant chooses the actual media players. The Node container does not need access to speakers, PipeWire, ALSA, or Bluetooth. The status sensor exposes the hymn catalog (including stable feast, category, season, office, and canonical-hour tags) and today's normalized LitCal day. Use `virtual_carillon.select_hymn` for fixed, random, or sequential selection; all liturgical filters, fallback behavior, dates, seeds, and recent exclusions are available in the action editor. For HA-owned schedules, copy `homeassistant/blueprints/automation/virtual_carillon/scheduled_routine.yaml` to `/config/blueprints/automation/virtual_carillon/` and configure the routine from Settings → Automations & scenes → Blueprints.
