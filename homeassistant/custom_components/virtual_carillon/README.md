# Virtual Carillon Home Assistant integration

Copy this directory into `/config/custom_components/virtual_carillon`, start the Node engine, and add **Virtual Carillon** from Settings → Devices & services. Enter the API URL and the server's `VIRTUAL_CARILLON_API_TOKEN` when prompted. The integration Options flow provides a UI for any number of server-owned routines, each with its own timing, ordered asset/hymn/delay actions, and Home Assistant media-player targets. The integration exposes a browsable media source and target-based actions, so Home Assistant chooses the actual media players. The Node container does not need access to speakers, PipeWire, ALSA, or Bluetooth. The status sensor exposes the hymn catalog (including stable feast, category, season, office, and canonical-hour tags) and today's normalized LitCal day. Use `virtual_carillon.select_hymn` for fixed, random, or sequential selection; all liturgical filters, fallback behavior, dates, seeds, and recent exclusions remain available for advanced actions. The scheduled-routine blueprint remains an optional advanced override.
