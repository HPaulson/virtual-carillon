# Changelog

## 0.1.0-beta.1

First public beta release.

- Generated bells, Westminster Chimes, Angelus signals, Office signals, and carillon hymn arrangements.
- Command-line playback, library browsing, local-output discovery, imported recordings, and an HTTP API.
- LitCal-aware Automatic hymn selection with seasonal, feast, category, saint, and canonical-hour preferences.
- Home Assistant integration with media browsing, actions, status sensor, speaker targets, and saved schedules.
- Home Assistant app images for `amd64` and `aarch64`, plus Docker Compose deployment.
