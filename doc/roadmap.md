# Roadmap

Virtual Carillon’s next work is guided by real-world behavior across its supported interfaces and deployments. The current priorities are:

- verify the Home Assistant app across its supported architectures;
- broaden the hymn catalog and its careful liturgical metadata; and
- refine scheduling, deployment, and accessibility from reproducible user reports.

Reliability, clear behavior, and respectful handling of liturgical material take precedence over adding features quickly. Please use the issue tracker for a reproducible bug report or a concrete feature request.
